# LuxxWallet feedback

Public bug reports and feature requests for [LuxxWallet](https://luxxwallet.com), by [Luxxfolio](https://luxxfolio.com/).

- [Report a bug](https://github.com/luxxfolio/luxxwallet-feedback/issues/new?template=bug_report.yml)
- [Suggest a feature](https://github.com/luxxfolio/luxxwallet-feedback/issues/new?template=feature_request.yml)
- [Browse existing reports](https://github.com/luxxfolio/luxxwallet-feedback/issues)
- [Report a security concern privately](https://github.com/luxxfolio/luxxwallet-feedback/security/advisories/new)
- [Get general help](https://luxxfolio.com/contact/)

You can read reports without an account. A GitHub account is needed to submit or comment. This repository contains the tracker and reporting instructions. LuxxWallet's source repository remains private.

## Before you report

Search existing reports first. If the same problem is already listed, add relevant details there instead of opening another issue.

Describe what you did, what you expected, and what happened. Include the affected area, coin/network, browser and operating system. Use a disposable wallet if you need to reproduce the problem.

**Issues and comments are public.** Never post recovery words, passwords, private keys, account recovery codes, authentication links or tokens, or backup files—even encrypted ones. Do not post wallet addresses, transaction IDs, balances, personal contact details, full page URLs, console dumps or network captures. If you add a screenshot, crop or cover account details, wallet names, addresses, balances, QR codes and anything private first.

Suspected security flaws belong in the [private security reporting flow](SECURITY.md). Do not describe an exploit in a public issue. Support will never need your recovery words, private keys or wallet password.

## Report status

| Status | Meaning |
| --- | --- |
| New | Received and awaiting review. This does not mean the bug has been confirmed. |
| Confirmed | We reproduced the problem or have enough evidence to confirm it. |
| In progress | A fix is being worked on. |
| Fixed | The fix has been released and checked. The closing update identifies the public release version or deployment date. |

Some reports need more information or duplicate an existing report. Those can be closed with an explanation and, for duplicates, a link to the original. A merged code change alone does not make a report fixed; reports stay open until the deployed result is checked.

Feature requests can be reviewed and discussed here. Opening or confirming a request is not a commitment to build it or a delivery date.
