# Security reporting

Report suspected LuxxWallet security vulnerabilities through [GitHub's private vulnerability form](https://github.com/luxxfolio/luxxwallet-feedback/security/advisories/new). Do not open a public issue or post exploit details in comments.

Use this route for problems that could expose wallet secrets, allow unauthorized transactions or account access, or compromise the wallet's security. Ordinary display problems and feature requests can use the public issue forms.

## What to include

- The affected wallet feature and public release version, or when you observed the problem.
- Reproduction steps using a disposable wallet and synthetic data.
- What access is required, what an attacker could do, and which users may be affected.
- A small, redacted proof of concept or screenshot if it helps explain the issue.

Never send recovery words, private keys, passwords, account recovery codes, session tokens, authentication links, or wallet backup files—even through the private form. Use placeholders for personal data, wallet addresses and transaction IDs. We can investigate the behavior without taking custody of a wallet.

Only test with your own disposable accounts and wallets. Do not access another person's wallet or data, send real funds to demonstrate an issue, disrupt services, or test mining infrastructure and third-party systems. If you encounter someone else's information, stop and describe the issue privately without copying or sharing that information.

If the private form is unavailable, use [Luxxfolio's contact page](https://luxxfolio.com/contact/) to request a private security contact. Do not include vulnerability details or wallet information in that initial message.

This page provides a reporting route. It does not announce a bug bounty, a payment offer, or a guaranteed response time.
